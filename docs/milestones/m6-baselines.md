# Retrospective baseline evaluation

After running the F5 ingestion, execute `python -m daybreak_api.evaluation` from `apps/api`. It reports one-month-ahead naive (last month) and seasonal naive (same month last year) errors over the final 12 available months. Each prediction uses only earlier observations in period order. MAE and RMSE are in percentage points, not percentages, and the script refuses missing or unordered months and insufficient history. This is a rolling one-step evaluation: once an actual month has occurred it can inform the next prediction.

The selected F5 series ends in 2020 in the documented retrieval. This is retrospective method evidence, not a present-day prediction or financial advice. Latest revised data may not have been available at each historic forecast origin; this evaluation does not establish a real-time backtest. No confidence intervals, ML candidate, model selection, anomaly detection or SHAP has been implemented. M6 remains open.

## Model card and independent verification

Intended use: reproducible analyst demonstration on one historical aggregate rate. Excluded uses: personal cash-flow prediction, eligibility, lending decisions and current-rate forecasting. No trained parameters or random seed are involved. Initial training history is 44 monthly observations; the observed download's final 12 months run February 2019–January 2020. Every exported prediction includes its training cutoff, actual and both baseline values; the CLI includes the snapshot SHA-256, source URL and retrieval timestamp. Missing months, invalid holdout types and non-finite/overflowing observations fail explicitly. A future-target perturbation test verifies earlier predictions cannot change.

A live download independently rerun on 2026-11-14 reproduced the M2 hash and 56 observations. Naive MAE = 0.06166666666666667 pp, RMSE = 0.10384282995630142 pp; seasonal-naive MAE = 0.38666666666666666 pp, RMSE = 0.4887739763939975 pp. These are descriptive results for this one revised snapshot and holdout, not evidence of generalization or calibrated uncertainty. The smaller error does not justify production model selection. Ruff, mypy and all 22 API tests passed with a disposable PostgreSQL database and locked dependencies on Python 3.13. M6 remains incomplete; no ML/SHAP benefit is asserted from 56 historical points.
