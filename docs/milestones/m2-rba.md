# RBA F5 ingestion: initial public-data slice

The command `python -m daybreak_api.rba_ingest` (from `apps/api`, after `alembic upgrade head` and configuring `DATABASE_URL`) downloads [RBA F5](https://www.rba.gov.au/statistics/tables/csv/f5-data.csv) over HTTPS with a 30-second timeout and a 10 MB limit. It validates the identifier, source, frequency and unit before committing in one transaction. Repeating an identical download does not duplicate snapshots or observations. Failed validation does not replace existing data. Snapshots retain the source file hash and retrieval time, and selected observations are versioned; the full CSV is not retained because other columns list third-party sources. Revision comparisons are possible by joining snapshot IDs. A newer snapshot replaces the whole current view, including deletions, rather than silently retaining removed periods.

Selected series: `FILRSAVR`, “Securitised housing loans; Average outstanding variable rate”, source listed in the file as “RBA; Securitisation System”, original monthly observations, per cent per annum. It is an aggregate rate, not an individual's loan rate. The download checked on 2026-11-14 contained 56 observations from June 2015 through January 2020; this is historical, not a current rate. The SHA-256 was `0c6e3b2a7cac7666bdb94769fa93a9e78ceceb5d0663f03b559df1bc2147fc3f`. Files may be revised; the file's publication date does not establish the date of each revision. Consult [F5 and its series breaks](https://www.rba.gov.au/statistics/tables/) before interpreting trends. Retrieval and loading are separate from claims of currentness.

Source: Reserve Bank of Australia, F5 Indicator Lending Rates, Securitisation System. The [RBA copyright notice](https://www.rba.gov.au/copyright/) section 5 applies to financial data, including attribution, no implied endorsement and third-party restrictions; it is not a blanket CC BY claim for financial data. This project ingests only the RBA-labelled series, not columns labelled CANSTAR or APRA. No real private financial records belong in this schema. Review terms before redistribution or adding other series.

`public_analytics.latest_rate` provides change in percentage points from the previous available observation and a three-observation rolling mean (not necessarily three consecutive calendar months). Both use the latest whole snapshot. The first change is null. Values are rates, so changes are not percentage growth. The initial data layer is not a full raw/staging/star warehouse, a banking portfolio, a validated forecast, or a Tableau/Excel reconciliation. Quality exception reporting, more sources, independent review and M2 acceptance remain outstanding.
