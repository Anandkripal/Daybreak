# Daybreak pilot protocol

A facilitator can use this script on a staging release with consenting participants. Use the scripted fictional circumstances and synthetic CSV only. Explain that participation is voluntary, and allow participants to stop or skip tasks. Do not request personal finances, hardship details, names or provider-contact records. Do not contact an organisation as part of the exercise.

| Task | Observe |
| --- | --- |
| A fictional NSW resident needs food support. Find a starting point, say what you would check about availability, and mark a fictional contact for follow-up. | Can the participant locate a relevant source and distinguish a directory link from verified availability? |
| Change the need to rebates and the region to another state. | Can the participant find the fallback and identify what they could try next? |
| Import the synthetic CSV shown in the [CSV contract](m3-private-csv.md). Identify net cash flow and delete the imported figures. | Can the participant explain what the value includes and tell when local figures have cleared? |
| Use keyboard navigation for a contact entry. Export and delete a fictional note. | Does focus remain predictable, and can the participant explain where the downloaded copy remains? |

For each task record completion without help, completion with one prompt, or not completed. Record the point of confusion and requested changes without verbatim personal disclosures. Report the session count, device/browser mix, task outcomes, accessibility failures, and limitations. Retain only anonymous task observations for the review and delete raw notes once the findings are recorded.

The automated synthetic browser regression has exercised contact creation, status, export and deletion, keyboard focus, CSV import and validation, and storage and request checks. It did not evaluate human comprehension, actual service access, comparative outcomes or assistive technology. No pilot participants or impact data are recorded.
