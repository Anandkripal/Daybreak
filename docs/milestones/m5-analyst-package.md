# M5 analyst package verification

Owner: logical Data Engineer, BI Analyst and QA. Issue: [#23](https://github.com/Anandkripal/Daybreak/issues/23). Scope: reproducible public/synthetic exports, SQL controls, actual Excel artifact, Tableau build instructions and measured query-plan example. No private user records, application contracts or production schema changes.

Independent review reran all four analytics tests and compared every selected RBA value and source hash against the original downloaded bytes. Exact match. SQLite connections were then explicitly closed to avoid resource warnings on Python 3.13.

Outputs live under `analytics/`. Python stdlib exports produce 48 synthetic category cash-flow rows, 12 monthly summaries, 36 synthetic assistance aggregates, 56 frozen historical RBA observations and five quality controls. Independent integer-cent controls reconcile annual income 4,380,000 cents, expenses 2,538,000 and net 1,842,000. The five Tableau views have actual source files and documented LOD, table calculations, parameters and action setup; no native Tableau file is claimed.

The Excel artifact contains five sheets: Summary, Cashflow, Rates, Assistance, Audit. Bundled artifact-tool performed recalculation, category-selector/SUMIFS and exact-match XLOOKUP perturbations, zero-income boundary handling and restoration. All 36 monthly SQL reconciliation differences are zero. Formula-error scan found no errors. Every sheet was rendered and visually inspected. Saved OpenXML tests verify formulas and cached controls, data validation, conditional formatting, two actual Excel Tables and a range-backed chart. These checks do not prove native Excel calculation. Native PivotTable export is documented unreliable in the authoring runtime, so a reproducible manual PivotTable and Power Query exercise is supplied rather than a false native-feature claim.

PostgreSQL 14.20 local benchmark: selective SUM over 200,000 temporary synthetic rows, five executions before and after a bucket index. Median execution was 14.008 ms before and 0.089 ms after. Both results are 1,055,400 cents; plans and buffers are preserved under `analytics/evidence/query-plan.json`. Warm cache, synthetic distribution, index build/storage cost exclusion and machine specificity limit interpretation. No index was added to the 56-row production rate dataset.

M5 remains in progress. Desktop Excel opening/recalculation, PivotTable refresh, Power Query support, native Tableau build and human accessibility/interpretation checks remain manual. The workbook and examples support technical review, not financial advice or observed assistance outcomes. M2 also remains incomplete: this package does not establish a full PostgreSQL raw/staging/star warehouse or broader APRA/ABS source coverage.
